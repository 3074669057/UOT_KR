# 5. 重点核查 A：表 4 reranker 循环性

## A.1 当前表 4 使用的 feature（逐字取自冻结脚本）

来源：`scripts/run_phase29_robust_rcuot_superiority.py:178`

```python
cols = ["heuristic_score", "conn_score", "abct_score", "rc_score", "bridge_proxy"]
```

模型：`LogisticRegression(max_iter=500, class_weight="balanced", random_state=42)`
目标：`in_gt_eval_only`（**真值对标签**）
阈值：τ = 0.7796（在同一开发标签上以 301 点网格选 F1 最优）

## A.2 feature 来源（逐项溯源）

| # | Feature | 来源代码 | 构成 | 是否来自被比较基线 |
|---|---|---|---|---|
| 1 | `heuristic_score` | `_flow_candidates_for_src` → `src/cross/domain/uot/flow_uot_candidate_subgraph.py:_heuristic_cost`；`score = 1/(1+cost)` | 金额误差 / 时间误差 / 路由（asset_group、route_id）/ 地址 / token symbol 的启发式代价 | **否**（但它是本管线自己的候选召回启发式，两个适配基线并不以它为输入） |
| 2 | `conn_score` | `_phase10s._baseline_scores(..., method="connector_style")` → `_connector_flow_score` | `0.35·amount + 0.30·time + 0.25·route + 0.10·addr_overlap`（fee_ratio 0.03） | **是 — Connector 风格基线的输出** |
| 3 | `abct_score` | `_phase10s._baseline_scores(..., method="abctracer_style")` → `_abctracer_flow_score` | `0.30·asset + 0.30·amount + 0.20·time + 0.10·addr_overlap + 0.10·risk` | **是 — ABCTracer 风格基线的输出** |
| 4 | `rc_score` | `_phase10s._rc_uot_from_frozen_pool(seed_dir, allowed, top_k=50)` | RC-UOT 冻结池的 UOT 软质量 | 否（本方法自身信号） |
| 5 | `bridge_proxy` | `df["bridge_proxy"] = df["abct_score"]`（脚本第 164 行） | **就是 `abct_score` 的副本** | **是 — 且为冗余复制** |

## A.3 是否包含 Connector / ABCTracer 输出

**是，且不止一项：**

- `conn_score` = Connector 风格基线的**原始分数**；
- `abct_score` = ABCTracer 风格基线的**原始分数**；
- `bridge_proxy` = `abct_score` 的**逐行复制**（脚本第 164 行逐字确认）。

**即 5 个特征中有 3 个位置（占 2 个独立信息源）来自被比较基线，其中 ABCTracer 分数被计入两次。**

此外还有**第二层不对称**（非特征层面，但同样相关）：候选池本身由本管线的 `_flow_candidates_for_src`（加宽时间窗 + route/asset 并集，top-K）生成。冻结审计确认三个方法共享**同一 K=50 候选池**（`FINAL_TABLE4_BASELINE_FAIRNESS_AUDIT.md` §3 "Parity locks that hold"），因此**召回侧是公平的**；不对称集中在**重排特征**与**调参预算**两处。

`out/multi_bridge_expansion/tifs_final_consolidation/FINAL_TABLE4_BASELINE_FAIRNESS_AUDIT.md` 已独立得出同一结论：

- §1 Headline：**"The Table 4 comparison is NOT calibration-parity-symmetric."**
- §3 Fairness verdict：`PARTIALLY_DOCUMENTED`
- §4：原稿已在 §4.6 加入 "Calibration asymmetry disclosed" 段落，但**未披露特征层面的构成**（该段只讲调参预算）

**因此 MUST-4 的本质是：调参不对称已被披露，特征循环性未被披露。**

## A.5 若删除这些 feature，需要哪些实验变化

| 方案 | 具体变更 | 影响 | 是否需要新实验 |

## C.2 判断：是否为同一指标
