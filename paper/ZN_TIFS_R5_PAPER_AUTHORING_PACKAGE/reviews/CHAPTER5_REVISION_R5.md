### 5.1 Experimental Setup and Evaluation Protocol

本节分列三类**互不相同**的数据资产。三类语料的角色、标签来源与可支持的结论都不同，全文所有数字均标注归属，**不得跨类引用**。

#### A. Celer supervised benchmark

Celer/cBridge 类桥 [34] 的**协议原生锚定监督数据**：7,296 个锚定交易对，聚合为 **5,735 条 ETH 源流**与 **7,122 条 BNB 目标流**，构成 **7,128 条监督流边**。标签拓扑为 1:1 **72.32%**、分流 1→N **27.51%**、合流 N→1 **0.17%**。替代时间窗（600 / 3600 s）下流标签数的扰动不超过 **±1.1%**。

**该数据的性质与边界**：这是**监督锚定数据**——真值来自桥协议的原生锚定关系 [G2]。它是本工作的开发与代价构造语料，**不是**非一对一结构的评测总体：其真实合流占比仅 **0.17%**，在开发语料上无法支撑任何关于合流行为的统计结论。本节 5.5 的覆盖/弃权分析（表 5、表 6）建立在该语料上。

#### B. Synthetic structural stress test

以 48 个结构模板为单元，每个模板从各桥真实 1:1 锚定出发，在**真实流特征上注入**结构：每模板 **1 个分流对（1→N）+ 1 个合流对（N→1）+ 1 个未匹配源 + 2 个噪声对**（每模板 7 条真值标签）。模板以 5 组实例生成。

**该数据的性质与边界（关键）**：这是**在真实流特征上以合成方式注入的结构**，**不是现实世界的非一对一标签**。因此：

- 5.2 的表 2/2b/2c 与 5.3 的表 3 所刻画的是**注入式结构**上的表示与排序效应，其外部推广受限于该生成器族；
- 本实验**不能**替代在真实非一对一标注数据上的方法评测。

#### C. Confirmatory holdout

三桥（**Celer、Multichain、PolyNetwork**）× 种子 **301–305** × 48 模板 = **720 个配对模板实例**（每模板方法行 3,600；真值标签行 5,040；缺失 0、重复 0；评测层 NaN 0）。这是**预先固定、hash-locked 的确认性保留集**：结果目录在执行前不存在，单次执行；执行后冻结脚本逐一致哈希；全部 15/15 求解单元收敛（UOT 最大终残差 9.886e-12）；由独立验证器从原始逐模板工件重算，主效应与判决在 1e-9 内一致。[G1]

**该数据的性质与边界**：

1. 720 个实例**共享同一注入结构构成**（每模板固定为 1 分流对 + 1 合流对 + 1 未匹配源 + 2 噪声对）。因此表 3 刻画的是**该生成器模板网格上的修复效应**。
2. **随机化结构**：48 个模板归属 **12 个模板族**（每族每种子 4 个实例），实例并非相互独立。主对比的配对 95% CI 按"桥内模板实例"重采样（B = 4,000，`RandomState(20240101)`；点估计按 模板→种子→桥→宏平均 分层聚合）。**按模板族聚类的 95% CI 为 [0.0676, 0.0849]**，seed→模板两阶段为 **[0.0677, 0.0831]**，真实依赖单元（基锚点）簇为 **[0.0708, 0.0803]**——三者均排除零，本章以其中最保守者为报告口径。[G11]
3. 该保留集是**同一冻结计划的两种解码器之间的对比**（见 5.3），不是方法对方法的对比。

#### Evaluation protocol

**指标。** 宏平均边精度、边召回、边 F1（主指标）；边包含召回与 Recall@3（结构表示）；严格精确恢复（预测边集须与结构真值完全一致）；交易级时间因果违例率；覆盖与弃权率。指标定义见补充 A.1。

### 5.2 Flow-Level Structural Representation

本节回答一个**表示层**问题：对于一对一输出语义之外的对应结构，运输计划能否在输出形式上**表达**它。**结论先行：能表达，但不能精确重建；且定量结果的分桥归属必须分清。**

#### (a) 1→N 与 N→1 的表达（edge containment）

在结构压力测试（B 类）上，UOT 的密集计划以**边包含口径**覆盖真值结构边：分流 **0.946 [0.907, 0.985]**、合流 **0.967 [0.913, 1.000]**；Recall@3（按源宏平均）为 **0.481 [0.418, 0.544]**。三桥忠实运行为 Celer **0.950 / 0.967**、Multichain **0.971 / 0.979**、PolyNetwork **1.000 / 1.000**。[G2, G3]

**口径限定（必须与数值同读）**：

1. **"边包含"（edge containment）不是"精确重建"（exact reconstruction）。** 边包含口径指解码计划对真值边赋予正质量（≥ 1e-9）即计为包含；该口径对应解码边精度约 **0.02**。0.946 / 0.967 的含义是**真值结构边被计划所包含的比例**，**不是**拓扑被正确重建的比例。
2. 全部数字来自 **B 类注入式模板网格**，非真实非一对一标签。
3. **Celer 的 0.946 / 0.967 来自 Celer 全流级管线**（流切分 + 富代价 + 非平衡运输 + 解码），Multichain / PolyNetwork 的对应数字来自三桥忠实运行配置。**两者口径相同但运行配置不同，故分表列出、不合并。**

#### (b) 一对一基线的 0 是输出语义限制，不是性能优势

一对一风格规则在边包含口径下为 **0**。这是**输出语义限制**：分流（1→2）要求源侧出度 ≥ 2，而一对一匹配器**每源至多输出一个目标**，故 1→2 结构在输出形式上不可能被表达。

**须修正的简化**：本稿早期草稿曾把该限制写成"分流/合流均为结构上不可能，恢复上限 ≤ 0.5"。代码级审计显示该约束是**源侧**的（出度 ≤ 1），因此 **2→1 合流在数据结构上是可以表示的**，其在基准上的零合流恢复是**成对金额/时间选择的经验结果**，而非结构性不可能。[G15]

**因此：该项作为输出语义的能力边界说明列出，不作为性能优势证明。**

#### (c) Unmatched 与 decoy（本实验内已量化）

未匹配语义在冻结压力阶梯上有直接测量。[G15] 三条结论：

**其一，未匹配/诱饵是能力存在性，不是检测性能。** 参照方法中只有传输类方法具备未匹配质量语义：Threshold-MM 通过"所有 C_ij > τ 则零边"实现**显式逐节点弃权**；Balanced-OT 在严格平衡边际、无 dustbin 的条件下**必须**把全部源质量运出，故其未匹配质量恒为 **1.000（即零剩余）**；UOT 在非平衡边际 + `allow_unmatched` 下以**剩余质量**作为一等弃权信号。一对一风格方法的未匹配仅作为候选过滤/零分的**副作用**存在，且**从不表示未匹配的目标**。

**其二，UOT 的未匹配质量由计划构造决定，不随注入的未匹配比例变化。** 在未匹配注入比例 0 / 0.10 / 0.20 / 0.30 / 0.40 五级阶梯上，UOT 的未匹配质量稳定在 **0.166–0.247（Celer）、0.166–0.320（Multichain）、0.244–0.259（PolyNetwork）**；Balanced-OT 各级恒为 **1.000**。[G15]

**该观察的边界**：由于边际由可观测质量构造，注入的额外未匹配源并不进入边际，故该阶梯**不构成对未匹配比例的检测性能评估**。未匹配质量反映的是计划残差，而非注入真值比例。

**其三，诱饵密度阶梯给出边级读数。** 在诱饵倍率 1× / 2× / 4× / 8× 上，UOT 的边 F1 由 **0.124（Celer）**、**0.057（Multi）**、**0.045（Poly）** 起逐步下降（8× 时 **0.071 / — / —**）；全局校准的阈值规则在该阶梯上边 F1 更高（Celer 0.298 → 0.113），Balanced-OT 保持高召回（0.921–1.000）但精度降至约 0.02–0.05。[G15]

**须显式声明的口径**：以上数字是 **B 类注入式压力阶梯上的能力存在性与稳健性读数**。它们**不构成**在真实数据上的未匹配检测/弃权性能评估（真实合流证据仅 85 单元，见 5.6(b)）。

#### (d) 严格口径与边级口径

在严格口径（预测边集须与结构真值完全一致）下，**五种方法在三个桥上的精确恢复均为 0.000**（共 15 个单元）。在边级指标上，全局校准的阈值规则（Threshold-MM，边 F1 **0.120–0.168**）**高于**两种传输解码（**≤ 0.040**）；覆盖分层传输解码在边精度上略高于严格平衡传输（**0.0148–0.0221** 对 **0.0095–0.0159**）。完整 15 行表见补充 A.4。[G4]

### 5.3 Conditional Decoding as Ranking Correction

本节是全文最核心、也是证据最强的一节，回答：**按原始运输计划数值排序会失真，方向条件化解码能否修复？**

**结论先行**：能，且在预先固定的保留集上得到确认。**但本节证明的是 ranking correction（排序修正），不是 transport solver superiority（传输求解更优）。**

#### (a) 失真诊断（开发种子 201–205，诊断性）

冻结计划的求解具有分解结构 P = diag(u)·K·diag(v)，K_ij = exp(−C_ij/ε)。由于核映射严格单调，**代价矩阵到核矩阵没有任何行/列序翻转**（C→K 翻转数恒为 0）；退化**全部**发生在 K→P 一步 [G8]：

- 开发种子上 **amount-free kernel diagnostic 的宏边 F1 = 0.3172**；
- 同一冻结计划按原始数值互选前 5 解码仅 **0.2374**；
- 即 **ΔF1 = −0.0798，配对 95% CI [−0.0847, −0.0751]**。

该退化被定位为**对偶缩放与边际竞争**：目标侧缩放 v 单独即可伤害 63.3% / 50.8% / 66.7% 的真值行秩；分流子边携带约为普通目标一半的中位 v；对边际做双侧均匀化干预后宏边 F1 恢复到 0.317 / 0.303 / 0.317。[G8]

**该 0.3172 的性质声明（关键）**：**它属于开发诊断，不是确认性保留集结果。** 它在解码器预先固定与保留集执行**之前**获得，使用开发种子 201–205，**不构成保留集证据，也不进入主对比**（表 3 以独立诊断行列出）。本节在此显式交代该上限，以避免读者误读 5.3(b) 的效应量。

#### (b) 主结果（确认性保留集，三桥 720 实例）

条件解码把宏平均边 F1 从 `RAW_UOT_PLAN_D4` 的 **0.2350** 提升到 `CONDITIONAL_UOT_D4` 的 **0.3104**；**Δ_primary = +0.075413，配对 95% CI [0.070557, 0.080312]**，完全位于零之上（表 3；图 5）。逐桥全部为正：Celer **+0.0826 [0.0743, 0.0918]**，Multichain **+0.0820 [0.0709, 0.0933]**，PolyNetwork **+0.0616 [0.0587, 0.0649]**。[G1]

基于冻结逐实例结果（**未重跑方法**）的三种替代重采样分别给出 [0.0676, 0.0849]（模板族聚类）、[0.0677, 0.0831]（seed→模板两阶段）、[0.0708, 0.0803]（基锚点簇），均不含零。判决为 `DECODER_REPAIR_CONFIRMED`，独立验证器在 1e-9 内复现。[G1, G11]

#### (c) 效应量的边界（必须与主结果同读）

**边界一：绝对水平低。** 主结果对应的解码**边精度为 0.1926**、边召回 0.8009、边 F1 0.3104。这是**方法内排序修正**的结果，**不是分诊级操作点**——按该操作点，每模板假正例由 18.93 升至 19.90（FP 比 1.051），假负例由 2.42 降至 1.19（FN 比 0.495）。[G1]

**边界二：本对比是同一冻结计划内两种解码器的对比，不是方法对方法的对比。** 表 3 中 `CONDITIONAL_BOT_D4`（0.3106）与 `CONDITIONAL_UOT_D4`（0.3104）相差 **−0.0003，95% CI [−0.0018, +0.0012] 包含零**。**因此本节不支持任何"非平衡松弛更优"的声明。**[G1]

**边界三：相对核排序的增益未被证明。** 见 (a)：开发期 amount-free 核解码已达 **0.3172**，**高于**保留集上条件解码的 0.3104。冻结判决给出的 recovery_fraction = Δ_primary / D = **1.0686**（D = 保留集上 amount-free 代价解码相对原始计划的增益 = 0.070569，门限 0.75）。[G1]

**边界三的解读（不得省略）**：条件解码修复的是**计划数值到对应排序的错位**，其代数通道是对偶缩放的消除（命题 1）。条件分数**不恢复核评分本身**——分母中保留了对侧竞争项——因此该修复的语义是"把已被求解器扭曲的排序拉回可用水平"，**而不是"运输求解优于核匹配"**。本稿**不作**后者声明。

**边界四：运输求解自身的增益小。** 相对直接核/支撑解码的传输计划级增量虽为正但很小：Δ_cost = **+0.0048 [0.0013, 0.0089]**，Δ_support = **+0.0104 [0.0062, 0.0152]**；主对比下三桥全部为正，但 **PolyNetwork 的两个二级对照为负**（各 **−0.0043 [−0.0065, −0.0024]**），已如实报告。平衡与非平衡条件解码的差异为 **−0.0003，95% CI [−0.0018, +0.0012] 包含零**。[G1]

#### (d) 机制方向

五项**预先固定**的机制指标全部指向修复方向：有害翻转率下降 **−0.2595**（行向）、**−0.2303**（列向）、**−0.5360**（分流子集）、**−0.5095**（合流目标），真值互选前 5 保留率上升 **+0.2035**。[G1]

这些是**观测性指标**，用于刻画修复的作用方式，**不构成完整因果分解**。组件压力阶梯（在开发封存流上逐项隔离代价组件）表明时间因果与未匹配质量是所隔离项中最敏感的两项；平衡与非平衡解码在不同压力级下表现为一致的**水平**差异而非**斜率**差异，与 (c) 边界四的观察一致。[G9]

#### (e) 保留集适用的边界

720 个模板实例**共享同一注入结构构成**，且每 4 个实例归属同一模板族。因此本节结论刻画的是**该生成器模板族网格上的修复效应**，**不是**在真实非一对一标注上的性能，其外部推广有待在充分多样语料上的方法评估。

### 5.4 Diagnostic Comparison with Transaction-Level References

本节回答：与交易级一对一参照相比，本管线在**何处占优、在何处不占优**。

**结论先行：只有在"流级非一对一对应"这一评测口径下，本管线才具备优势；在召回、校准、分流/合流恢复、覆盖调整有效召回与近一对一锚定口径上，参照方法更强。本文不声称全面超过已有方法。**

#### (a) 闭集原生诊断：口径不同，不可相互排名

Connector 原生管线在**闭合候选集**上的交易对精确匹配 F1 = **0.9736**（预测 6,954 / 正确 6,937 / 无匹配 342），冻结记录标记 `closed_set_warning`。[G12]

**该数字的用途与禁令**：其度量单元是**闭合候选集上的交易对精确匹配**，与本章其余全部**流级边级**指标**口径不同**。因此：**二者不可相互排名，该数字也不构成对本管线的比较基准。** 列出它的目的是让读者看到——当桥事件证据完整且对应近似一对一（A 类语料 72.32% 为 1:1）时，现有一对一工具的适用性很强；这恰是本工作的**动机边界**，而非本工作要取代的对象。

掩码退化阶梯进一步刻画该边界：移除接收方字段时 Connector 无法评估（`N/A`）；移除金额字段时其**零预测**（F1 由 0.9736 降至 **0.000**，`status = ZERO_PREDICTIONS_AFTER_AMOUNT_MASK`）。同一掩码下本管线保持可评估（见 5.5(d)）。[G12]

#### (b) 校准预算不对称对照（诊断性，非优势证据）

**关键披露：表 4 的操作点不是本管线的通用形式，而是包含基线相关特征的重排配置。** 冻结记录显示，该操作点的选定候选 `rcuot_q_precision_rerank` 是一个有监督重排器：

```
LogisticRegression(cols = [heuristic_score, conn_score, abct_score, rc_score, bridge_proxy],
                   threshold = 0.7796)
```

**即其输入特征包含 Connector 风格分数（`conn_score`）与 ABCTracer 风格分数（`abct_score`）。** 该重排器在开发种子 52–71 上选择，保留集种子 292–311 单次评估；两个适配基线使用固定常量、**无开发选择步骤**。[G5]

- **命名**：称为 **Diagnostic reranking configuration**，**不称为"UOT-Q 方法"**（UOT-Q 指 5.3 的传输计划 + 条件解码 + 覆盖弃权管线；两者不是同一对象）。

- **结论边界**：该配置的精度/F1 领先**不构成**对未获同等调参预算基线的优势证据。**本文不声称全面超过已有方法。**

#### (b) 本实验能证明什么、不能证明什么

**能证明**：

1. 在 Celer 全管线上，运输表示以**边包含**口径覆盖 1→N / N→1 真值结构边（0.946 / 0.967），三桥忠实运行为 0.950–1.000（表 2/2b）；传输类方法具备未匹配质量语义，一对一方法不具备（表 2c）。
2. 原始计划的数值排序存在由**对偶缩放与边际竞争**造成的失真；**方向条件化解码**在预先固定的三桥保留集上把宏边 F1 从 0.2350 提升到 0.3104（Δ = +0.075413，CI 排除零，三种替代重采样一致）。
3. 联合时间可采过滤可在覆盖 0.8453 下把交易级时间因果违例率降至 **0**，置换标签对照降至 0.0001；四项泄漏审计全部通过。
4. 流级扇出在开发语料之外**真实存在**（v4/v5 两窗口，仅数据）。

**不能证明（九条，含本报告新增）**：

1. **外部方法性能。** 方法在充分多样的**独立语料**上的性能**尚未建立**。此前的一次外部执行在取得有效性能前因实现缺陷终止、未重跑；两个后开发期数据审计均未通过预先注册的充分性标准（v4：G = 7 < 8；v5：max-share 0.6200 > 0.5 且保守 G = 2），且**两语料上均未运行方法**。
2. **真实非一对一标注数据上的性能。** 5.2 与 5.3 的全部定量结论建立在 **B 类注入式半合成结构**上；真实合流证据仅 **85**（v4）/ **76**（v5）个单元，在 25,621 / 39,595 条真值边中约占 **0.48% / 0.19%**。**合流方向的结论主要来自半合成压力测试。**
3. **可操作的重建精度。** 严格精确拓扑恢复在 5 方法 × 3 桥上均为 **0.000**；流级压力操作点精度 **0.192**。本管线最现实的用法是**召回导向的候选生成与排序卫生**，而非自动结构重建。
4. **传输求解相对核排序的增益。** 开发期 amount-free 核解码已达 **0.3172**，**高于**保留集条件解码的 **0.3104**（recovery_fraction = 1.0686）。条件解码修复的是**计划数值到排序的错位**，**不是核评分本身**；对侧竞争项仍保留在条件分数中。**本文不作"运输求解优于核匹配"的声明。**
5. **非平衡松弛的专属价值。** Δ_bot = **−0.0003**，CI **[−0.0018, +0.0012] 包含零**；Δ_cost / Δ_support 虽为正但极小（+0.0048 / +0.0104）；PolyNetwork 二级对照为负（−0.0043）。
6. **公平预算下的基线优势。** **不存在**公平预算的基线比较：适配基线为校准预算不等的诊断性对照（表 4），且其操作点为**含基线分数特征**的有监督重排器；在召回、校准、分流/合流恢复、覆盖调整有效召回与近一对一锚定口径上，**参照方法更强**。**本文不声称全面超过已有方法。**

**结论**：本次修复在不新增实验、不改动任何冻结数字的前提下，把**三处可致命风险全部转为已披露局限**，并使最强证据（5.3 确认性保留集）**强度零损失**。剩余 14 项中，**D1 与 D3 无法通过改写消除**——D1 需要新语料上的方法执行，D3 需要移除基线特征的消融重排，二者均超出本次授权范围，建议作为作者决策项保留。
