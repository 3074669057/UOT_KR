# Supplement A — Evaluation Definitions and Structural Tests

## A.1 度量定义

- **边包含召回（edge-inclusion recall）**：解码计划对真值边赋予正质量（≥1e-9）即计为包含；密集计划口径，**非精确拓扑恢复**。排序单元/候选集/真值条件/并列/聚合规则按桥内模板实例定义。
- **Recall@3**：按源宏平均的排序包含指标（候选集 = 该源的全部目标候选；真值条件 = 真值边进入前 3）。
- **严格精确恢复（strict exact-set recovery）**：预测边集与结构真值完全一致才计恢复。
- **tx-CVR**：交易级时间因果违例率。
- **覆盖与弃权分母**：覆盖分母 = 具备事件支撑的候选；弃权 = 未覆盖候选占比。
- **配对分层 95% CI**：桥内模板实例配对、分层重采样（B = 4,000，固定随机状态）。

## A.2 结构压力测试设计

48 模板 × 5 实例（共 240 组）；真实流提供特征锚，1→2 / 2→1 / 未匹配 / 诱饵结构施加其上；三桥（Celer、Multichain、PolyNetwork）。

## A.3 能力核对（原表 S2）

- 一对一风格解码器（Connector 风格 / ABCTracer 风格）：结构上不能输出 1→2 边集；合流方向部分支持；不支持全局质量分配；未匹配仅拒绝级弃权。
- Threshold-MM：支持 1→2 / 2→1，不支持全局质量分配；有未匹配处理。
- Balanced-OT：支持分/合流与全局分配；无未匹配质量机制。
- RC-UOT-Q：支持分/合流、全局质量分配、质量级未匹配与弃权。
- 三桥严格评估中 Multichain / PolyNetwork 上两个一对一风格基线的精确恢复与边 P/R/F1 均为 0.000。

## A.4 严格评估全表（原表 S3，15 行）

三桥 × 五方法；分流/合流精确恢复列全部 0.000；边精度/召回/F1 与正文披露一致（阈值规则边 F1 0.120–0.168；传输方法 ≤ 0.040；RC-UOT-Q 精度 0.015–0.022 对平衡 OT 0.010–0.016）。
度数准确率 / FP 列（按表内方法顺序）：Celer 5.84 / 5.84 / 67.7 / 680.8 / 539.0；Multichain 6.00 / 5.80 / 71.0 / 1069.6 / 925.4；PolyNetwork 6.00 / 6.00 / 107.5 / 852.8 / 743.6。

## A.5 严格全零的解释（原附录 I）

其一，严格口径要求预测边集与结构真值完全一致，密集计划天然给出非零质量扩散；其二，解码点固定（k = 5 与固定阈值），不做事后选择；其三，半合成模板的诱饵与未匹配结构使严格一致在数值上不可达。三个原因均为结构性，非评估器伪影。

# Supplement B — Conditional Decoding and Confirmatory Evaluation

## B.1 命题 1 完整推导（原附录 G）

设 P = diag(u)K diag(v)，u_i, v_j, K_ij > 0。行向：c_j = Σ_l P_lj = Σ_l u_l K_lj v_j = v_j Σ_l u_l K_lj，故 S^row_ij = P_ij / c_j = u_i K_ij v_j / (v_j Σ_l u_l K_lj) = u_i K_ij / (Σ_l u_l K_lj)——v_j 精确消去。列向对称：r_i = u_i Σ_l K_il v_l，S^col_ij = K_ij v_j / (Σ_l K_il v_l)——u_i 精确消去。恒等式对平衡与非平衡熵 OT 同形式成立（分解结构不依赖 KL 罚项）。

## B.2 零支撑处理（原附录 G）

c_j → 0 或 K_ij → 0 时条件分数退化为 0/0 或 0 量级：实现中对零列质量施加数值下限、对零支撑候选直接置为未覆盖；该处理仅影响数值稳定性，不改变命题在正支撑上的结论。

## B.3 确认性协议（原附录 D；不含内部哈希清单）

- 保留集构成：三桥、720 个配对模板实例、种子 301–305（未触碰；逐种子产物未访问，数字转录自冻结合并层记录）。
